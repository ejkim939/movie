# 🎬 영화티켓 요금 안내 및 계산기

상영관, 시간대, 요일 및 관람 인원에 따른 영화 티켓 요금을 한눈에 확인하고, 각종 할인 혜택을 실시간으로 계산해 볼 수 있는 **Streamlit 기반 웹 애플리케이션**입니다.

\---

## ✨ 주요 기능

1. **영화티켓 요금표 안내**

   * **2D 상영관**: 조조(10:00 이전), 일반(평일/주말) 기준 청소년 및 어른 요금 안내
   * **특별관 3D**: 시간대 및 연령 구분 없는 단일 요금 안내
2. **할인 혜택 안내**

   * **인원 할인**: 청소년 및 어른 총합 4인 이상 관람 시 총금액의 **15% 할인**
   * **제휴카드 결제**: 총금액의 **20% 할인**
   * *참고: 할인 혜택은 중복 적용되지 않으며, 가장 유리한 혜택이 우선 적용됩니다.*
3. **실시간 요금 계산기**

   * 상영관 종류, 시간대, 요일, 인원수(청소년/어른)를 선택하여 실시간으로 기본 요금과 최종 결제 금액 계산
   * 사용자가 직접 할인을 선택하거나, **자동 적용** 옵션을 통해 최대 할인율 자동 계산 및 차감 금액 표시
